# PTA 编程题解与思路分享

![Status](https://img.shields.io/badge/Status-持续更新中-blue)
![Language](https://img.shields.io/badge/Language-C-green)

本仓库用于分享 PTA 平台 C 语言编程作业的**解题思路、核心逻辑与易错点**，仅供同学们学习参考。

## ⚠️ 免责声明（请务必阅读）

1. **本仓库仅用于个人学习与思路交流，严禁直接复制粘贴提交作业。**
2. **因直接抄袭（或大面积复制）导致的一切后果，包括但不限于平时分扣除、PTA 查重判定作弊、课程挂科等，由使用者自行承担。**
3. 代码仅代表个人解法，不代表标准答案，也不保证在 PTA 上 100% AC（可能有时会有更优解）。
4. 如果老师或平台认为本仓库内容侵权，请通过 Issue 联系我删除，我会第一时间处理。

## 📖 使用建议（怎么用才有效）

- **先自己写**：拿到题目，先自己思考、动手写一遍，哪怕报错了也是一种积累。
- **卡住了再看思路**：点开对应题目的文件夹，看看我写的 `README.md`（思路分析），理解了再自己去写代码。
- **实在写不出再看代码**：不要直接复制！试着把代码关掉，凭记忆和理解重新写一遍，这样才真正是你的东西。
- **欢迎交流**：如果你有更好的思路，或者发现我代码里的 Bug，欢迎提 Issue 或 Pull Request。
